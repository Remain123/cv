## 关于我 · About Me

我是 **刘益帆（Louis Liu）**，目前就读于**曼彻斯特大学通信与信号处理硕士**，拥有利物浦大学电气与电子工程（通信方向）及西交利物浦大学通信工程学习背景。

我曾在**腾讯、隆基绿能及汽车零部件企业**实习，参与项目管理、技术销售支持与工程协调，积累了跨部门沟通、客户需求梳理、进度跟踪和数据分析经验。

在校园期间，我曾担任**西交利物浦大学篮球社社长**，全程策划并组织多场大型活动，统筹活动筹备、外部赞助对接与现场执行，积累了团队组织、资源协调和活动管理经验。

在技术研究方面，我围绕 **LoRa 射频指纹识别与物联网设备身份认证**开展深度学习项目，使用 Python 和 GNU Radio 进行信号采集、数据处理及模型开发，并对比 CNN 与 Transformer 的设备识别表现。

除工程与项目实践外，我拥有**多年的虚拟货币交易经验**，并有**游戏饰品投资管理人经历**。我关注宏观政治与经济，对相关议题有一定的研究与了解。

我注重将**工程背景与项目管理相结合**，从技术原理、实际需求和执行过程出发，推动方案落地。

在个人理念上，我是一名**唯物主义者、实用主义者**，重视客观事实与实践检验，关注方法的可行性及实际效果。

**技能与工具：** Python · MATLAB · GNU Radio · Excel 数据分析 · 项目协调 · 中英文沟通
